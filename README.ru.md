# playterm

[한국어](README.md) | [English](README.en.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | [Português (Brasil)](README.pt-BR.md) | [Deutsch](README.de.md) | [Français](README.fr.md) | [繁體中文](README.zh-TW.md) | **Русский**

**SSH, Telnet, последовательные консоли и удалённый рабочий стол Windows — во вкладках одного окна.**

playterm — нативное терминальное приложение на Rust (egui, alacritty_terminal, russh и IronRDP). Для Windows x64 и ARM64 оно поставляется как один переносимый исполняемый файл без установки среды выполнения. Для macOS доступны приложения для Apple silicon и Intel.

Это руководство на русском языке описывает ветку разработки `master`. Уже выпущенные возможности перечислены в [изменениях v0.8.0](docs/releases/v0.8.0.md) и [примечаниях к выпускам](https://github.com/playok/playterm/releases). [Подробный справочник на английском](README.en.md) содержит все настройки и инструкции по разработке и сборке пакетов.

## Возможности

- SSH, Telnet, последовательные порты и RDP во вкладках и разделённых областях окна.
- Выбор нескольких узлов через Ctrl/Shift+щелчок, одновременное подключение и шаблоны с узлами и их расположением.
- Аутентификация SSH с ключами, сертификатами и внешними агентами; промежуточные хосты, перенаправление `-L` / `-R` / `-D` и X11.
- Панель SFTP, передача ZMODEM (`sz` / `rz`), автовход, макросы, одновременный ввод и журналы сеансов.
- Хранилище паролей с шифрованием мастер-паролем (Argon2id + XChaCha20-Poly1305).
- Импорт сеансов PuTTY, Xshell и SecureCRT, папки и цвета вкладок.
- Интерфейс на десяти языках, светлая и тёмная темы, выбор шрифта, поиск в истории вывода и международные кодировки.

## Загрузка и запуск

Загрузите пакет для своей ОС и процессора со страницы [GitHub Releases](https://github.com/playok/playterm/releases).

- **Windows:** распакуйте ZIP и запустите `playterm.exe`. Устанавливать распространяемый пакет VC++ не требуется. Начиная со следующего выпуска стандартные пакеты содержат несжатые исполняемые файлы; пакеты UPX будут доступны отдельно. Формат конкретного выпуска указан в его описании.
- **macOS 11 и новее:** откройте DMG и перетащите `playterm.app` в Applications; также можно использовать ZIP. Сведения о подписи, нотариальном заверении и первом запуске приведены в примечаниях к выпуску и [руководстве macOS на английском](README.en.md#macos-app).
- Установка обновлений из приложения доступна только в Windows. В macOS приложение открывает страницу загрузки.

В разделе Инструменты → Настройки выберите язык **Русский**. Изменение сразу отображается; Отмена возвращает прежний выбор. Сохранённый язык остаётся после перезапуска. Язык интерфейса и кодировка удалённого соединения задаются независимо.

## Подключение

Сохраните соединение в диспетчере узлов или воспользуйтесь быстрым подключением. В строке `playterm>` неподключённой вкладки можно ввести `ssh user@host`, `telnet host`, `serial COM3 115200`, `rdp user@host` или `help`.

Подключение также можно запустить из командной строки:

```sh
playterm ssh://user@host:22
playterm -i ~/.ssh/id_ed25519 ssh://user@host
playterm -L 8080:db:5432 -D 1080 ssh://user@host
playterm --cp949 telnet://192.168.0.1
playterm serial://COM3:115200
playterm rdp://user@host
```

В локальной командной строке `sites` показывает сохранённые узлы, а `open имя` или `open номер` подключает узел. Команды `ls` / `dir`, `cd` и `pwd` работают с локальными файлами. После завершения соединения командная строка появляется снова. [Список команд на английском](README.en.md#local-command-prompt).

## Повседневная работа

- **Узлы и разделение окна:** перетащите вкладку к краю другой группы вкладок. При удалении папки узлов её содержимое перемещается в родительскую папку; сами узлы сохраняются. Пароли PuTTY, Xshell и SecureCRT не импортируются.
- **Копирование и вставка:** Ctrl+Shift+C / Ctrl+Shift+V. Ctrl+C копирует выделение, а если его нет — отправляет `^C`. Можно включить копирование при выделении и вставку правой кнопкой. Многострочная вставка запрашивает подтверждение, если удалённая программа не использует bracketed paste.
- **Поиск и отображение:** Ctrl+Shift+F ищет также в истории вывода. Ctrl+колесо и Ctrl+= / Ctrl+- / Ctrl+0 меняют размер шрифта. Сочетания клавиш для конкретной ОС указаны в меню.
- **Одновременный ввод:** Ctrl+Shift+I направляет клавиши и вставленный текст также в другие выбранные вкладки. Проверяйте оранжевые отметки получателей; отдельную вкладку можно исключить через контекстное меню.
- **Панель команд и макросы:** Ctrl+Shift+M показывает панель; Enter отправляет текст, Shift+Enter добавляет строку. Макросы поддерживают `@wait`, `@sleep`, `@if` и другие инструкции. Используйте `{password}` вместо записи самого пароля.
- **Автовход и поддержание соединения:** задайте шаги «ожидать приглашение → отправить текст» с `{user}` и `{password}`. Выберите сообщения протокола SSH/Telnet или ввод текста, предотвращающий тайм-аут ввода на устройстве.
- **Кодировка:** автоопределение различает только UTF-8 и CP949. Shift_JIS, EUC-JP, GBK, Big5, кодовые страницы Windows и другие кодировки выбираются явно. [Структура переводов и кодировок](docs/i18n.md).

## Передача файлов и RDP

Панель SFTP рядом с терминалом SSH позволяет загружать и отправлять файлы, создавать папки, переименовывать и удалять. На устройствах без SFTP запустите на сервере `sz file` для загрузки на ПК или `rz` для отправки с ПК (на сервере требуется lrzsz). ZMODEM работает через SSH, Telnet и последовательный порт; Ctrl+C отменяет передачу.

RDP отображает удалённый рабочий стол во вкладке с изменяемым разрешением, звуком и вводом Unicode. Общий буфер обмена, папки и принтеры доступны **только в Windows**. Поддерживается RD Gateway; микрофон и Kerberos пока не поддерживаются. При первом подключении проверьте отпечаток сертификата: изменение сохранённого сертификата приводит к отказу в соединении. [Подробности RDP на английском](README.en.md#remote-desktop-rdp).

## Аутентификация и настройки

При первом SSH-подключении проверьте отпечаток ключа хоста. Изменение сохранённого ключа блокирует соединение. Включайте перенаправление агента SSH (`-A`) и доверенное перенаправление X11 (`-Y`) только для доверенных серверов. Локальное подписание закрытыми ключами RSA ограничено; см. [аутентификацию на английском](README.en.md#ssh-authentication-order) и [меры защиты для RSA](docs/security-rsa-223.md).

В Windows настройки находятся в `%APPDATA%\playterm\config\`. Переменная `PLAYTERM_CONFIG_DIR` позволяет выбрать другую папку для переносимого использования или изолированных проверок.

| Файл | Содержимое |
| --- | --- |
| `sessions.toml` | Узлы и шаблоны без паролей |
| `settings.toml` | Язык, внешний вид, клавиши, макросы и обновления |
| `vault.toml` | Сохранённые пароли, зашифрованные мастер-паролем |
| `known_hosts` | Доверенные ключи хостов SSH |
| `known_rdp_hosts` | Доверенные отпечатки сертификатов RDP |

Если забыть мастер-пароль, сохранённые пароли восстановить невозможно. Макросы хранятся открытым текстом: не записывайте в них секретные данные напрямую.

## Сборка и разработка

Требуется **Rust 1.95 или новее**. Для Windows нужны средства сборки MSVC из Visual Studio 2022, а для ARM64 — также LLVM/clang. Для macOS нужны Xcode command line tools. Зависимости Linux перечислены в [руководстве для участников](CONTRIBUTING.md).

```sh
cargo build --release --locked
cargo fmt --all -- --check
cargo clippy --locked --workspace --all-targets -- -D warnings
cargo test --locked --workspace
```

В Windows доступны `build.cmd` и `release.cmd`; пакеты macOS создаются через `scripts/package-macos.sh`. [Сборка и подпись на английском](README.en.md#building).
