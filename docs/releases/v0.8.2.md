# playterm v0.8.2

## Highlights

- 저장된 비밀번호를 사용하는 SSH 사이트의 반복 입력을 줄인 수정 릴리스입니다. 실제 저장 사이트 접속에서 추가 비밀번호 입력 없이 로그인되는 것을 사용자와 확인했습니다.

## Fixes

- 사이트에 저장된 비밀번호가 있으면 암호화된 SSH 키의 passphrase 입력 없이 먼저 비밀번호로 접속합니다. 서버가 키를 먼저 요구해 비밀번호가 거부된 경우에만 passphrase 를 묻고, 키를 통과한 뒤의 `password` 추가 인증은 저장된 계정 비밀번호로 처리합니다. OTP 등 keyboard-interactive 추가 인증에는 저장된 비밀번호를 보내지 않습니다. (#271)

## Compatibility and update notes

- 기존 저장 사이트와 비밀번호 볼트를 그대로 사용합니다. 잠긴 볼트는 저장된 사이트에 처음 접속할 때 마스터 비밀번호로 잠금 해제하며, 잠금 해제 상태에서는 저장된 계정 비밀번호를 사용합니다. 프로그램 시작 즉시 마스터 비밀번호를 묻는 동작은 이번 릴리스에 포함되지 않습니다.
- 업데이트 적용 후 프로그램을 재시작해야 합니다.

## Known limitations

- 서버가 암호화된 SSH 키나 OTP 등 추가 인증을 요구하면 해당 입력은 필요합니다. 이번 수정은 서버의 추가 인증을 생략하지 않습니다.
- 기존 제한은 [v0.8.1 변경 내역](v0.8.1.md)을 확인하세요.
