# 다음 릴리스 변경 내역

UNRELEASED — v0.6.0 이후 개발 변경을 여기에 기록합니다.

## Highlights

- 비밀번호 볼트의 새 Argon2id 기본값은 64 MiB, t=3, p=1입니다. 기존의 약한 비용은 올바른 마스터 비밀번호로 잠금 해제할 때 자동으로 재암호화합니다.
- 볼트 생성·잠금 해제는 백그라운드에서 진행하며, 완료 전 취소할 수 있습니다.
- 도구 → 저장된 호스트 키·인증서에서 SSH 키와 RDP 인증서 지문을 확인하고 삭제할 수 있습니다. 삭제는 별도 확인이 필요하며, 다음 연결에서도 새 지문을 확인해야 합니다.

## Fixes

- 연결·재접속·비밀번호 매크로에서 앱이 보관하는 비밀번호 사본을 드롭 시 지우고, 디버그 출력은 계속 가립니다.
- 프로필 설정 타입을 `playterm-types`로 분리했습니다. `playterm-config`만 빌드·시험할 때 네트워크 런타임과 IronRDP·OpenSSL을 빌드하지 않으며 `sessions.toml` 형식은 유지합니다.
- 여러 창이 같은 RDP 서버의 최초 인증서를 저장할 때 프로세스 잠금으로 중복을 막습니다. 확인 중 다른 키·인증서가 기록되면 덮어쓰거나 연결을 계속하지 않습니다.

## Compatibility and update notes

- `{password}` 매크로는 실행할 때마다 대상과 에코·로그 노출 위험을 확인해야 합니다. 연결 후 자동 실행은 중단되며, 도구 → 매크로에서 확인 후 직접 실행할 수 있습니다. 프롬프트를 기다리는 자동 로그인은 유지합니다.
- 소스 빌드 최소 Rust 버전은 1.95입니다. GUI 의존성인 egui/eframe 0.37도 이 버전을 요구합니다. CI에서 Rust 1.95.0으로 Linux 전체 워크스페이스를 빌드합니다.

## Known limitations

- 이전 릴리스의 제한은 [v0.6.0 변경 내역](v0.6.0.md)과 [검증 기록](../validation.md)을 확인하세요.
