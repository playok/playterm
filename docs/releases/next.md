# 다음 릴리스 변경 내역

UNRELEASED — v0.7.0 이후 개발 변경을 여기에 기록합니다. v0.7.0에 포함한 사항은 [해당 버전 변경 내역](v0.7.0.md)을 확인하세요.

## Highlights

- 사이트별 **이전 SSH 장비 호환** 옵션을 추가했습니다. 켠 사이트에만 SHA-1 키 교환·MAC와 AES-CBC를 허용하며, 현대적인 알고리즘을 우선합니다 (#246).

## Fixes

- SSH 호스트 인증서 principal의 `*`·`?` wildcard를 지원합니다. 빈 principal과 신뢰하지 않는 CA의 거부 정책은 유지합니다 (#244).
- 여러 프로세스가 사이트·폴더·템플릿을 저장할 때 최신 파일을 잠금 안에서 읽고 해당 변경만 적용합니다. 사이트 관리 창을 열 때도 목록을 갱신하며, 저장 실패 시 메모리와 볼트의 후속 변경을 막습니다 (#245).
- 손상된 `settings.toml`을 고유한 `.broken` 파일에 보존한 뒤 기본값을 사용합니다. 보존에 실패하면 원본을 덮어쓸 수 있는 상태로 앱을 시작하지 않습니다 (#253).
- 개인 키 파일의 Unix 권한이 다른 사용자에게 열려 있으면 안내하고, 자동 로그인 입력란에 평문 저장과 `{password}` 사용을 안내합니다. 릴리스 서명 도구의 문자열·바이트 배열 키 버퍼를 사용 후 지웁니다 (#253).

## Compatibility and update notes

- Windows의 X11 쿠키 조회·생성에는 `PLAYTERM_XAUTH`에 신뢰하는 `xauth.exe`의 절대 경로가 필요합니다. 현재 디렉터리나 PATH에서 실행 파일을 찾지 않습니다 (#253).
- 사용하지 않는 내부 인자 `--open`을 제거했습니다. 새 창으로 열기는 같은 프로세스 안에서 연결을 유지한 채 탭을 옮깁니다. README의 RDP 공유 기능 Windows 제한과 평문 로그 설명을 정정했습니다 (#254).

## Known limitations

- 기존 제한과 RSA 잔여 위험은 [v0.7.0 변경 내역](v0.7.0.md)을 확인하세요.
- #247~#252의 신규 기능과 #254의 공급망 정책은 구현 완료가 아닙니다. [이슈별 검토 결과와 후속 조건](../review-244-255.md)을 확인하세요.
