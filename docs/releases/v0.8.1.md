# playterm v0.8.1

## Highlights

- 실행 중인 탭의 인코딩을 바로 바꿀 수 있습니다. 상태바의 인코딩 표시를 클릭하거나 툴바의 인코딩 버튼, 도구 메뉴나 탭 우클릭 메뉴의 "인코딩" 하위 메뉴에서 고르며, "자동 감지"를 고르면 다시 감지합니다. RDP 탭에는 표시되지 않습니다. (#269)

## Fixes

- 자동 인코딩 감지가 첫 판정 후에도 출력을 계속 확인해, 접속 중 `export LANG=...`이나 `su` 등으로 원격 인코딩이 UTF-8 ↔ CP949(EUC-KR)로 바뀌면 따라 전환합니다. 전환 전에 이미 표시된 출력은 다시 그리지 않습니다. 고정 인코딩을 지정한 탭은 바뀌지 않습니다. (#269)

## Compatibility and update notes

- Windows 앱 내 업데이트 후에는 재시작해야 합니다. macOS는 새 릴리스 다운로드 페이지를 안내합니다.
- 설정 마이그레이션은 없습니다. 실행 중 변경한 인코딩은 해당 탭에만 적용되고 사이트 설정에는 저장되지 않습니다.

## Known limitations

- 자동 인코딩 감지는 UTF-8/CP949(EUC-KR)를 대상으로 하며, 다른 인코딩은 직접 선택해야 합니다.
- 기존 제한은 [v0.8.0 변경 내역](v0.8.0.md)을 확인하세요.
