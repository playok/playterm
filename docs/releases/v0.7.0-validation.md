# v0.7.0 게시 및 릴리스 권한 검증

2026-11-07 09:41:25 KST에 [v0.7.0](https://github.com/playok/playterm/releases/tag/v0.7.0)을 정식 게시했다. 태그 소스는 `13bae39c82fb95ed10c943ed384774e842ce1762`이며 릴리스 준비 PR #242까지 포함한다. 이 문서는 게시 후 검증으로, 태그와 공개 바이너리를 바꾸지 않는다.

## #206 실제 태그 게시 검증

[릴리스 워크플로 42314652619](https://github.com/playok/playterm/actions/runs/42314652619)의 Windows·macOS·publish 잡이 모두 성공했다. 실제 `push` 이벤트의 `v0.7.0` 태그에서 테스트·최적화 빌드·패키징·서명 검증·파일 업로드·릴리스 게시가 실행됐다.

| 잡 | 실제 로그의 토큰 권한 | 결과 |
| --- | --- | --- |
| [Windows](https://github.com/playok/playterm/actions/runs/42314652619/job/128224202259) | `Contents: read` | 테스트, x64/ARM64 빌드, 기본/UPX 패키징 및 체크섬 서명 성공 |
| [macOS](https://github.com/playok/playterm/actions/runs/42314652619/job/128224201987) | `Contents: read` | 테스트, ARM64/x64 빌드, ZIP/DMG 생성 및 최종 앱 검증 성공 |
| [publish](https://github.com/playok/playterm/actions/runs/42314652619/job/128241026999) | `Contents: write` | 두 빌드의 산출물을 받아 실제 정식 릴리스 게시 성공 |

태그의 모든 checkout은 `persist-credentials: false`이고, 두 빌드 잡의 로그에서 Rust/cargo 단계 전 checkout 인증 제거도 확인했다. publish의 `fetch-depth: 0`, 명시적 `GH_TOKEN` 및 `--verify-tag`를 유지한 상태에서 게시가 성공했다. 따라서 #206의 마지막 기준인 권한 축소 후 실제 태그 게시 동작을 확인했다.

## 공개 파일 검증

- 공개된 Windows 기본/UPX × ARM64/x64 ZIP 4개와 macOS ARM64/x64 ZIP·DMG 4개를 다시 내려받았다. 여덟 SHA-256이 공개 체크섬과 일치했다. [기계 판독 결과](v0.7.0-verification.json)에 실제 해시를 보존했다.
- Windows `SHA256SUMS.txt`의 Ed25519 서명을 앱의 기존 공개 키로 검증해 `signature OK`를 확인했다. 개인 키는 조회하지 않았다.
- Windows 네 실행 파일은 버전 `0.7.0`이며 PE 아키텍처가 각 패키지와 일치했다. 네 파일 모두 Authenticode `NotSigned`이고 게시자 인증서가 없었다.
- macOS 두 ZIP의 앱·제품 버전은 `0.7.0`, Mach-O 아키텍처는 각각 ARM64/x64였다. CI에서 최종 ZIP 추출본 및 DMG 마운트본의 앱이 `codesign --verify --deep --strict`와 designated requirement 검증을 통과했다. DMG 무결성과 Applications 링크도 패키징 단계에서 검사했다. 앱은 ad-hoc 서명이며 Developer ID 서명·공증은 없었다. 공개된 macOS 파일 네 개는 검증한 CI 아티팩트와 해시도 일치했다.
- GitHub latest가 `v0.7.0`이며 draft/prerelease가 아닌 것을 확인했다. 공개 본문에 네 사용자 설명 섹션, v0.6.0 비교 링크, RSA 인증 호환성·잔여 위험, 실제 서명 상태, 8개 패키지 및 체크섬·서명 안내가 보존됐고 초안 표시는 없었다.

## 테스트와 실제 화면의 범위

준비 PR의 [Windows·macOS·Ubuntu·Rust 1.95 CI](https://github.com/playok/playterm/actions/runs/42314216358)와 [퍼징·커버리지 CI](https://github.com/playok/playterm/actions/runs/42314215843)가 통과했다. 태그 소스의 master CI 42314645965도 성공했다. 로컬 Windows ARM64에서 locked 전체 워크스페이스 테스트, rustfmt, 릴리스 설명 회귀 3개와 두 lockfile의 metadata 검증을 통과했다.

태그 준비 빌드의 실제 Windows 앱에서 [About의 Version 0.7.0](../screenshots/validation/v070-about.png)과 실행 파일의 파일·제품 버전 `0.7.0`을 확인했다. 이는 공개 ZIP의 최종 로그인 검증과 구분한다. 공개 후에는 Windows 데스크톱이 잠겨 있어 4종의 OTP 입력 후 로그인 및 v0.6.0→v0.7.0 실제 업데이트·재시작은 수행하지 못했다. 잠금 해제 후 이어서 검증할 항목으로 남기며 잠금을 우회하지 않았다.

macOS 네이티브 GUI, 깨끗한 OS 첫 실행, 정식 서명·공증과 실장비·절전 복귀는 #192·#194·#195에 남아 있다. #207의 Draft PR #221은 이 태그에 포함하지 않았으며 #223의 RSA 의존성 근본 해결도 완료로 기록하지 않는다. 로컬 증거는 `target/release-validation/v0.7.0/`와 `target/gui-validation/070-about/`에 있다.
