# playterm v0.7.0

v0.6.0 이후 이 태그까지의 기능과 수정 사항입니다. 설정과 저장된 키를 백업하고 아래 인증 변경 사항을 확인한 뒤 업데이트하세요.

## Highlights

- 비밀번호 볼트의 새 Argon2id 기본값은 64 MiB, t=3, p=1입니다. 기존의 약한 비용은 올바른 마스터 비밀번호로 잠금 해제할 때 새 salt로 재암호화합니다. 볼트 생성·잠금 해제는 백그라운드에서 진행하며 완료 전 취소할 수 있습니다. [#209](https://github.com/playok/playterm/issues/209), [#210](https://github.com/playok/playterm/issues/210)
- 도구 → 저장된 호스트 키·인증서에서 SSH 키와 RDP 인증서 지문을 검색·삭제할 수 있습니다. 삭제는 별도 확인이 필요하며, 다음 연결에서도 새 지문을 확인해야 합니다. [#213](https://github.com/playok/playterm/issues/213)
- `known_hosts`의 `@cert-authority`로 신뢰한 CA가 서명한 SSH 호스트 인증서를 지원합니다. 호스트·유효기간·서명·폐기 여부를 검증합니다. [설정과 범위](https://github.com/playok/playterm/blob/v0.7.0/docs/ssh-host-certificates.md), [#214](https://github.com/playok/playterm/issues/214)
- macOS ARM64/x64에 앱과 Applications 링크가 들어 있는 DMG를 추가했습니다. 기존 ZIP도 계속 제공합니다. [#241](https://github.com/playok/playterm/pull/241)

## Fixes

- 연결·재접속·비밀번호 매크로에서 앱이 보관하는 비밀번호 사본을 드롭 시 지우고 디버그 출력에서 가립니다. [#210](https://github.com/playok/playterm/issues/210)
- 여러 창이 같은 RDP 서버의 최초 인증서를 저장할 때 프로세스 잠금으로 중복·덮어쓰기를 막습니다. 확인 중 다른 키·인증서가 기록되면 연결을 계속하지 않습니다. [#213](https://github.com/playok/playterm/issues/213)
- 프로필 ID용 OS 난수 생성 실패와 SFTP 취소 맵 오류를 패닉 대신 실패로 알립니다. Unix에서 볼트와 저장 중 임시 파일은 0600 권한을 사용합니다. [#215](https://github.com/playok/playterm/issues/215)
- 원격 포워딩(`-R`)은 바인드 주소와 포트를 함께 비교합니다. 같은 포트라도 주소가 다르면 각각의 목적지로 전달하며, 빈 주소/localhost는 목적지가 하나로 확인되는 루프백 규칙에만 대응합니다. [#218](https://github.com/playok/playterm/issues/218)
- 릴리스 빌드의 토큰은 읽기 권한만 사용하고 checkout 자격 증명을 남기지 않습니다. 게시 작업만 쓰기 권한을 사용합니다. 서명 CLI 회귀 테스트, 제한 시간 파서 퍼징과 커버리지 CI도 추가했습니다. [#206](https://github.com/playok/playterm/issues/206), [#217](https://github.com/playok/playterm/issues/217)

## Compatibility and update notes

- **로컬 RSA 개인 키 파일 서명을 차단합니다.** RUSTSEC-2023-0071 임시 완화로, 파일명과 관계없이 명시적·기본 키·fallback·점프 호스트에 적용합니다. Ed25519/ECDSA 또는 보안 상태를 별도로 확인한 외부 에이전트 등으로 전환하세요. 키를 자동 삭제·변환하지 않습니다. 외부 에이전트는 별도 signer 경로이며 그 구현의 안전성을 보장하지 않습니다. [#223](https://github.com/playok/playterm/issues/223)
- 서버가 SSH 호스트 인증서를 제공하면 신뢰할 CA를 명시적으로 등록해야 합니다. 인증서 검증 실패를 일반 키의 최초 신뢰 질문으로 우회하지 않습니다.
- `{password}` 매크로는 실행할 때마다 대상과 에코·로그 노출 위험을 확인해야 합니다. 연결 후 자동 실행은 중단되며 도구 → 매크로에서 확인 후 직접 실행할 수 있습니다. 프롬프트를 기다리는 자동 로그인은 유지합니다.
- 기존 `sessions.toml` 형식은 유지합니다. 내부 설정 타입은 `playterm-types`로 분리했고, 소스 빌드 최소 Rust 버전은 1.95입니다. [#211](https://github.com/playok/playterm/issues/211), [#212](https://github.com/playok/playterm/issues/212)
- 업데이트 설치 후 재시작이 필요합니다. Windows 기본 패키지는 미압축이며 기존 UPX 사용자도 자동 업데이트 후 기본 미압축 변형으로 전환됩니다. UPX는 선택 다운로드로 유지합니다.

## Known limitations

- **RSA 의존성의 공식 취약점 해결을 뜻하지 않습니다.** `rsa 0.10.0-rc.18`은 SSH/RDP 의존성에 남아 있고 RustSec의 패치 버전은 아직 없습니다. RDP의 개인 키 연산 도달성은 미검증입니다. 공급망 검사 PR #221과 이슈 #207·#223은 미완료이며 이번 태그에 Draft #221의 변경은 포함하지 않습니다. [완화와 잔여 위험](https://github.com/playok/playterm/blob/v0.7.0/docs/security-rsa-223.md)
- 코드 서명·공증 상태와 체크섬은 아래 Downloads의 실제 빌드 결과를 확인하세요. 미서명 Windows/ad-hoc macOS 빌드는 SmartScreen·Gatekeeper 경고가 발생할 수 있고 백신 오탐 해소를 보장하지 않습니다. [#192](https://github.com/playok/playterm/issues/192)
- 네이티브 macOS GUI, 실제 x64 Windows 장비, 장비 콘솔·RDP/RD Gateway 조합과 절전·네트워크 전환은 미검증 범위가 남아 있습니다. 크로스 빌드나 ARM64에서의 x64 에뮬레이션 성공을 해당 장비 실행으로 간주하지 않습니다. [#194](https://github.com/playok/playterm/issues/194), [#195](https://github.com/playok/playterm/issues/195)
- 기존 프로토콜 제한은 [v0.6.0 변경 내역](https://github.com/playok/playterm/blob/v0.7.0/docs/releases/v0.6.0.md)과 [호환성 표](https://github.com/playok/playterm/blob/v0.7.0/docs/compatibility.md)를 확인하세요.
