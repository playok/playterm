# playterm v0.8.3

## Highlights

- 사이트에 접속할 때 마스터 비밀번호를 더 이상 묻지 않습니다. 저장된 비밀번호를 여는 키는 OS 키체인(macOS 키체인, Windows 자격 증명 관리자, Linux Secret Service)에 보관합니다. 마스터 비밀번호 대신 사이트 목록을 내보내거나 가져올 때만 비밀번호를 입력합니다.
- 사이트 목록을 저장된 비밀번호와 함께 암호화된 `.ptsites` 파일로 내보내고, 다른 PC에서 가져올 수 있습니다. 내보낼 때 정한 비밀번호로 파일을 암호화합니다. 가져올 때 에이전트 포워딩, X11, 포트 포워딩, 자동 로그 폴더, 접속 후 매크로, 점프 호스트, 키 파일, 사용자 인증서, 프록시, 자동 로그인, RDP 공유 폴더와 게이트웨이처럼 주의할 설정이 있는 사이트는 체크가 해제된 채 표시되어 확인 후 가져옵니다.
- 도구 모음에 주소 입력칸이 생겼습니다. IP나 도메인(`user@host:port` 형식 가능)을 입력하고 Enter를 누르면 바로 연결합니다. 포트 23은 Telnet으로 연결하고, 포트 없이 호스트만 입력하면 빠른 연결 창이 열립니다. 주소처럼 보이는 입력은 이름이 같은 사이트가 있어도 그 주소로 연결합니다.
- 사이트별 프록시(HTTP CONNECT, SOCKS4/4a, SOCKS5)와 DNS 조회 위치를 설정할 수 있습니다. HTTP Basic과 SOCKS5 인증은 접속할 때 프록시 비밀번호를 묻습니다. 프로토콜 목록에 Telnet/SSL(시스템 인증서로 검증), Raw TCP, rlogin이 추가되었습니다. (#250)

## Fixes

- SSH 서버가 응답하지 않아 재연결이 대기 중일 때 Ctrl+C로 바로 취소할 수 있습니다. 연결 시간 제한까지 기다리지 않습니다. (#275)
- CI에서 간헐적으로 실패하던 연결 취소 테스트를 고쳤습니다. 앱 동작에는 변화가 없습니다. (#278)

## Compatibility and update notes

- 기존 마스터 비밀번호 볼트는 처음 한 번 마스터 비밀번호를 입력하면 OS 키체인 방식으로 전환됩니다. 전환 후에는 마스터 비밀번호를 묻지 않습니다. 저장된 사이트와 비밀번호는 그대로 유지됩니다.
- macOS에서는 처음 사용할 때 키체인 접근 허용을 물을 수 있습니다. 키체인에 저장하지 못하면 오류로 알리며, 키를 파일에 대신 저장하지 않습니다.
- Linux에서 Secret Service가 없으면 키를 설정 폴더의 개인 파일(권한 0600)에 저장하고, 그 사실을 한 번 알립니다.
- 내보낸 `.ptsites` 파일에는 비밀번호가 포함됩니다. 파일과 내보내기 비밀번호를 안전하게 보관하세요.
- Windows는 앱 내 업데이트 후 재시작해야 합니다. macOS는 새 릴리스 다운로드 페이지를 안내합니다.

## Known limitations

- rlogin은 로그인 핸드셰이크와 기본 입출력만 지원합니다. 예약된 소스 포트와 긴급 데이터를 이용한 창 크기 협상은 지원하지 않습니다.
- 프록시, Telnet/SSL, Raw TCP, rlogin은 자동 테스트로 검증했고 실제 장비 접속은 검증하지 않았습니다.
- 기존 제한은 [v0.8.2 변경 내역](v0.8.2.md)을 확인하세요.
