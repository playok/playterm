# playterm

[English](README.en.md) | **한국어**

**관리하는 모든 장비를 한 창에서 — SSH, Telnet, 시리얼 콘솔, Windows 원격 데스크톱을 탭으로.**

playterm은 Rust(egui + alacritty_terminal + russh + IronRDP)로 만든 Windows 터미널입니다.
x64·ARM64용 실행 파일 하나로 동작하며, 설치나 런타임 설치가 필요 없습니다.

## 주요 기능

- **SSH · Telnet · 시리얼 · RDP** 를 한 창에서 함께 사용
- **화면 분할**: 탭을 가장자리로 끌어 여러 세션을 동시에 보기
- **여러 사이트 한 번에 연결**: Ctrl/Shift+클릭으로 골라 한꺼번에 열거나, **템플릿**(탭·좌우·위아래·격자)으로 저장해 더블클릭으로 열기
- **SSH**: 키 인증(OpenSSH / PuTTY `.ppk`, Pageant, Windows OpenSSH 에이전트), `-L` / `-R` / `-D` 포트 포워딩, 터미널 옆 SFTP 탐색기
- **원격 데스크톱**: 탭 크기에 맞춘 해상도 자동 조절, 클립보드 공유, 한글 IME 입력, 서버 인증서 고정
- **비밀번호 볼트**: 저장한 비밀번호를 마스터 비밀번호로 암호화 (Argon2id + XChaCha20-Poly1305)
- **네트워크 장비 작업에 편리**: 자동 로그인, 여러 탭 동시 입력, 세션 로그, 접속 유지, CP949(EUC-KR) 및 인코딩 자동 감지, ZMODEM 받기(`sz`)
- **사이트 관리**: 폴더, 사이트별 탭 색상, PuTTY 세션 가져오기, 연결 전 탭의 `playterm>` 명령 프롬프트
- 한국어 / English UI, 다크 / 라이트 테마

## 구조

| 크레이트 | 역할 |
|---|---|
| `crates/playterm-term` | 터미널 에뮬레이션(alacritty_terminal), UTF-8/CP949 변환, 색상 팔레트 |
| `crates/playterm-net` | SSH(russh) / Telnet / 시리얼 / RDP(IronRDP) 전송, 세션 이벤트·명령 채널, ZMODEM 받기 |
| `crates/playterm-config` | 세션 목록(`sessions.toml`), 비밀번호 볼트(`vault.toml`), 설정(`settings.toml`) |
| `crates/playterm-i18n` | 한국어 / 영어 UI 문구 |
| `crates/playterm` | GUI 앱(eframe/egui): 렌더링, 키보드/IME 입력, 대화상자 |

## 빌드

```powershell
cargo build --release
```

- Rust 1.90+ 와 MSVC 빌드 도구(Visual Studio 2022)가 필요합니다.
- **Windows ARM64에서는 clang도 필요합니다** (암호 라이브러리 `ring` 빌드용):
  `winget install LLVM.LLVM` 후 `C:\Program Files\LLVM\bin` 을 PATH에 추가.

### 스크립트 (cmd)

| 명령 | 하는 일 |
|---|---|
| `build.cmd` | 릴리스 빌드 → `target\release\playterm.exe` (`build.cmd debug` 는 디버그 빌드) |
| `release.cmd` | clippy 검사 → 테스트 → ARM64·x64 패키지 → `dist\` 에 zip 과 `SHA256SUMS.txt` (`release.cmd x64` 처럼 하나만도 가능). exe 는 UPX 로 압축 (`noupx` 로 끔) |

두 스크립트 모두 LLVM(clang) 경로를 알아서 PATH 에 넣고, `--locked` 로 빌드해 `Cargo.lock` 에 적힌 의존성 버전만 씁니다.
`release.cmd` 는 커밋하지 않은 변경이 있으면 멈춥니다(시험용 패키지는 `release.cmd dirty`).

### GitHub 릴리스 (자동 빌드)

`v` 로 시작하는 태그를 푸시하면 GitHub Actions(`.github/workflows/release.yml`)가 clippy 검사 → 테스트 → x64·ARM64 패키지(UPX 압축)를 만들어
그 태그의 릴리스에 zip 두 개와 `SHA256SUMS.txt` 를 올립니다. 태그는 `Cargo.toml` 의 버전과 같아야 합니다.

```powershell
git tag v0.1.0
git push origin v0.1.0
```

Actions 탭에서 **Release → Run workflow** 로 직접 실행하면 릴리스는 만들지 않고, 같은 빌드 결과를 워크플로 아티팩트로 남깁니다(빌드 시험용).

### 릴리스 패키지

```powershell
rustup target add x86_64-pc-windows-msvc     # 최초 1회
release.cmd                                  # 또는: pwsh scripts\package.ps1 -Upx (검사·테스트 없이 패키지만, -Upx 를 빼면 압축 안 함)
```

- zip 안의 exe 는 **UPX** 로 압축됩니다(약 21 MB → 7 MB). UPX 는 환경변수 `UPX_EXE`(경로나 명령 이름)와 그 SHA-256 을 담은 `UPX_SHA256` 으로
  지정하거나, 없으면 고정 버전(5.3.0)을 공식 GitHub 릴리스에서 `tools\upx` 로 한 번 받아 씁니다. 받은 zip 과 그 안의 `upx.exe` 는 SHA-256 을 확인하고,
  실행할 때마다 `upx.exe` 를 새 임시 폴더에 복사해 그 사본을 실행 직전에 다시 확인한 뒤 실행합니다(ARM64 exe 는 UPX 5.3.0 이상 필요). 압축된 exe 는 창(프로세스)마다 메모리에서 풀리므로 창을 여러 개 띄우면 메모리를 조금 더 씁니다.
  UPX 압축 exe 는 백신이 오탐하는 경우가 있으니, 필요하면 `release.cmd noupx` 로 압축 없이 만드세요.
- C 런타임을 정적으로 링크하므로(`.cargo/config.toml`) VC++ 재배포 패키지 없이 실행됩니다.
- DLL 은 System32 에서만 불러옵니다(`/DEPENDENTLOADFLAG` 링크 옵션과 시작 시 `SetDefaultDllDirectories`). exe 와 같은 폴더(예: 다운로드 폴더)에
  같은 이름의 DLL 이 있어도 쓰이지 않습니다.
- 화면은 OpenGL(glow)로 그리고, OpenGL 을 쓸 수 없는 환경(GPU 없는 VM 등)에서는 자동으로 wgpu(DX12)로 전환합니다.
  환경변수 `PLAYTERM_RENDERER=wgpu` 또는 `glow` 로 강제할 수 있습니다.
- 아이콘은 `assets/make_icon.py` 로 생성합니다 (`playterm.png`, `playterm.ico`).

## 실행

```powershell
playterm                                  # 연결 대화상자
playterm ssh://user@host:22               # 바로 접속
playterm --cp949 telnet://192.168.0.1     # CP949(EUC-KR) 구형 장비
playterm -i ~/.ssh/id_ed25519 ssh://user@host   # 키 파일 지정
playterm -L 8080:db:5432 -D 1080 ssh://user@host   # 포트 포워딩 (OpenSSH 와 같은 형식, -R 도 지원)
playterm serial://COM3:115200             # 시리얼 콘솔 (8N1)
playterm rdp://user@host                  # Windows 원격 데스크톱
```

## 로컬 명령 프롬프트

연결되지 않은 탭(새 탭 Ctrl+Shift+N, 연결이 끊긴 탭, 탭이 하나도 없을 때)에는 `playterm>` 프롬프트가 뜹니다.
접속 명령은 그 탭에서 바로 연결되고, 연결이 끝나면 다시 프롬프트로 돌아옵니다.

| 명령 | 동작 |
|---|---|
| `ssh [-p 포트] [-l 사용자] [-i 키] [-L/-R/-D ...] [--cp949] [사용자@]호스트[:포트]` | SSH 접속 (사용자 생략 시 Windows 사용자 이름) |
| `telnet 호스트 [포트]` | Telnet 접속 |
| `serial COM3 [속도]` | 시리얼 콘솔 |
| `rdp [사용자@]호스트[:포트]` | 원격 데스크톱 |
| `ping [-t] [-n 횟수] [-w 밀리초] [-l 크기] [-4\|-6] 호스트` | 응답 확인 (Windows `ping` 과 같은 옵션, 기본 4번, `-t` 는 Ctrl+C 로 멈출 때까지, `-c 횟수` 도 가능). 관리자 권한 없이 Windows ICMP API 로 보내고, 끝나면 손실률과 왕복 시간 통계를 보여 줍니다 |
| `open` | 사이트 관리 창 |
| `open 이름\|번호` | 저장된 사이트 접속 (번호는 `sites` 의 번호, 이름 일부만 써도 됨) |
| `sites [검색어]` | 저장된 사이트 목록 |
| `ls [-l] [-a] [경로]`, `dir [/a] [경로]` | 파일 목록 (`*.log` 같은 패턴 가능, `-a`: 숨김 파일 포함) |
| `cd [경로]`, `pwd` | 폴더 이동 (`cd` 만 쓰면 홈, `cd ..`, `cd D:`) / 현재 폴더 |
| `new` / `quick` | 새 사이트 / 빠른 연결 창 |
| `r` | 마지막 연결 다시 접속 |
| `clear`, `exit`, `help` | 화면 지우기, 탭 닫기, 도움말 |

←/→/Home/End 로 줄 편집, ↑/↓ 로 이전 명령, Ctrl+C 로 입력 취소, Ctrl+L 로 화면 지우기.

## 메뉴 · 사이트 관리

- 창 상단 메뉴: **파일 · 편집 · 보기 · 도구 · 탭 · 창 · 도움말**. 단축키가 있는 항목은 메뉴에 함께 표시됩니다.
- **도움말 → 오픈소스 라이선스**: playterm(MIT)과 실행 파일에 포함된 오픈소스 구성 요소 전부의 라이선스를 보여 줍니다(검색, 항목별 라이선스 전문과 소스 저장소).
  목록은 빌드할 때 `cargo metadata` 로 자동으로 만들어지므로 의존성이 바뀌어도 따로 고칠 것이 없습니다.
- **파일 → 사이트 관리** (Ctrl+Shift+S): 왼쪽은 폴더별 사이트 목록(검색), 오른쪽은 선택한 사이트의 설정.
  - [새 사이트] / [새 폴더] / [복제] / [삭제], 오른쪽 아래 [연결] / [저장] / [되돌리기]
  - **폴더**는 여러 단계로 만들 수 있습니다(`운영/web`). 폴더를 우클릭하면 이 폴더에 새 사이트 · 새 하위 폴더 · 이름 바꾸기 · 삭제,
    사이트를 우클릭하면 연결 · 복제 · 폴더로 이동 · 삭제, 빈 곳을 우클릭하면 새 사이트 · 새 폴더가 나옵니다.
    폴더 이름을 바꾸면 안의 사이트와 하위 폴더가 함께 옮겨지고, 폴더를 삭제해도 안의 사이트는 지워지지 않고 위 폴더로 옮겨집니다.
  - 폴더는 노란 폴더 아이콘, 사이트는 연결 종류 배지(SSH 초록 · TEL 주황 · COM(시리얼) 보라 · RDP 파랑)로 구분합니다. 왼쪽 사이트 목록도 같습니다.
  - **[트리] / [그리드]** 로 보기를 바꿉니다. 그리드는 사이트마다 한 줄(종류 · 이름 · 접속 대상 · 사용자 · 폴더)이며, 고른 보기는 기억됩니다.
  - 저장하지 않고 다른 사이트로 옮기거나 창을 닫으면 저장할지 묻습니다.
  - 목록에서 더블클릭하면 접속하고 창이 닫힙니다.
- 왼쪽 사이트 목록(Ctrl+Shift+B)은 빠른 접속용입니다. [관리] 또는 우클릭 → 편집 으로 사이트 관리 창이 열립니다.
- **파일 → PuTTY 세션 가져오기**: PuTTY 에 저장된 세션(레지스트리)을 골라서 사이트로 가져옵니다.
  호스트·포트·사용자·키 파일·인코딩·터미널 타입·포트 포워딩·시리얼 설정을 옮기고, 이미 있는 사이트는 기본으로 선택 해제합니다.
  비밀번호는 PuTTY 가 저장하지 않으므로 옮겨지지 않습니다. rlogin/raw 세션은 건너뜁니다.
- **탭 색상**: 사이트 관리 창의 "탭 색상" 에서 사이트마다 색(빨강·주황·노랑·초록·청록·파랑·보라·분홍·회색)을 정하면, 그 사이트의 탭에 색이 칠해지고(아래 막대 + 옅은 바탕) 왼쪽 사이트 목록에도 표시됩니다. 운영 서버를 빨강으로 두는 식으로 구분할 때 씁니다.
  열려 있는 탭은 탭 우클릭 → **탭 색상** (또는 탭 메뉴 → 탭 색상) 으로 그 탭만 바꿀 수 있습니다.
- **새 창으로 열기**: 탭 우클릭 (또는 탭 메뉴) → 새 창으로 열기. playterm 을 하나 더 실행해 그 탭의 접속을 새 창에서 엽니다(원래 탭은 그대로).
  비밀번호는 넘기지 않습니다. 저장된 사이트는 새 창에서 볼트 잠금을 풀어 저장된 비밀번호로 접속하고, 그 밖의 접속은 새 창에서 다시 묻습니다.
  파일 → **새 창** 은 빈 창(로컬 프롬프트)을 엽니다.
- **탭 도킹 (화면 나누기)**: 탭을 끌어서 다른 탭 묶음의 왼쪽·오른쪽·위·아래 가장자리에 놓으면 화면이 나뉘어 여러 세션을 함께 봅니다. 탭 줄 안에 놓으면 그 묶음의 탭이 됩니다.
  나뉜 화면 사이의 경계를 끌어 크기를 바꾸고, 클릭한 창이 현재 탭이 됩니다(파란 테두리). 묶음의 마지막 탭을 닫으면 그 자리는 없어지고, 새 탭은 현재 탭이 있는 묶음에 열립니다.
- **여러 사이트 한 번에 연결**: 왼쪽 사이트 목록에서 **Ctrl+클릭**(하나씩 더하기/빼기)·**Shift+클릭**(범위)으로 여러 사이트를 고르면 목록 아래에 `N개 선택 [연결] [나란히 ▾] [템플릿 저장]` 이 나옵니다(선택한 사이트 우클릭 메뉴에도 있음).
  [연결] 은 탭으로, [나란히] 는 좌우·위아래·격자로 화면을 나눠 엽니다. 볼트에 저장된 비밀번호를 쓰는 사이트가 있으면 마스터 비밀번호는 한 번만 묻습니다.
- **템플릿**: 자주 함께 여는 사이트 묶음에 이름을 붙여 저장합니다(선택 후 [템플릿 저장]). 이름, 배치(탭/좌우/위아래/격자), 사이트와 여는 순서를 정하고, 사이트 목록 맨 위 **템플릿** 에서 더블클릭(또는 우클릭 → 모두 연결)으로 한 번에 엽니다.
  우클릭 → 편집 / 삭제. 템플릿은 `sessions.toml` 에 함께 저장되고, 사이트를 지우면 템플릿에서도 빠집니다.

## 화면 설정 · 찾기

- **도구 → 설정**: 언어(한국어 / English), 화면 테마(다크 / 라이트 / Windows 설정 따르기), 글꼴, 크기, 색 테마, 스크롤백 줄 수. 바꾸는 즉시 열린 탭에 미리 보이고, [취소] 하면 되돌아갑니다.
  - 글꼴: 이 PC 에 설치된 모든 글꼴(시스템 + 사용자 설치, 고정폭 글꼴이 위에, 목록 안에서 검색 가능) 또는 [파일에서…] 로 TTF/OTF/TTC 파일. 한글은 글꼴에 없으면 맑은 고딕으로 표시합니다.
  - 색 테마: Campbell, One Half Dark/Light, Solarized Dark/Light, Tango Dark, Dracula, Gruvbox Dark
  - 연결 시간 제한 (기본 15초, 3~300초): SSH · Telnet · RDP 서버가 이 시간 동안 응답하지 않으면 연결을 포기합니다. TCP 연결부터 로그인을 마칠 때까지
    (SSH 핸드셰이크·인증, RDP 의 TLS·로그인 포함) 적용되고, 호스트 키 확인이나 비밀번호 입력을 기다리는 시간은 세지 않습니다. 새 연결부터 적용됩니다.
  - 복사 / 붙여넣기: 터미널에서 쓸 키를 고릅니다.
    - 복사: **선택하면 바로 복사**(PuTTY 방식, 기본 끔) · Ctrl+C(선택 영역이 있을 때만, 없으면 ^C) · Ctrl+Shift+C · Ctrl+Insert
    - 붙여넣기: Ctrl+V · Ctrl+Shift+V · Shift+Insert · **오른쪽 클릭**(PuTTY 방식, 기본 끔 — 켜면 메뉴는 Ctrl+오른쪽 클릭) · **가운데 클릭**(기본 끔)
    - 끈 키는 원격으로 그대로 전달됩니다 (예: Ctrl+V 를 끄면 vim 등에서 ^V 로 쓸 수 있음). 메뉴와 단축키 목록에는 켜 둔 키가 표시됩니다.
    - 대화상자·입력칸에서는 설정과 관계없이 Ctrl+C/V/X, Ctrl/Shift+Insert, Shift+Delete 가 늘 동작합니다.
    - 원격 복사 (OSC 52, 기본 켬): tmux · vim 등 원격 프로그램이 이 PC 클립보드에 쓸 수 있습니다. 지금 보고 있는 탭에서만, 1MB 까지,
      쓸 때마다 화면 아래에 알림이 뜹니다. 원격에서 클립보드를 읽는 것은 항상 막혀 있습니다.
    - 붙여넣기 보호(bracketed paste)가 켜진 프로그램에는 붙여넣는 글 안의 ESC 를 모두 빼고 보내, 붙여넣은 글이 명령으로 바로 실행되지 않게 합니다.
    - 붙여넣기 확인 (기본 켬): 붙여넣기 보호가 없는 곳에 여러 줄을 붙여넣으면 줄마다 명령이 실행될 수 있어, 내용을 미리 보여 주고 확인을 받습니다.
    - 터미널에서 복사하면 화면 아래에 `복사됨 · 104자 · 3줄 “pla…~>”` 처럼 글자 수·줄 수와 앞뒤 3글자가 잠깐 올라왔다 사라집니다
      (줄바꿈은 ⏎, 탭은 → 로 표시). 엉뚱한 범위를 복사했는지 바로 알 수 있습니다.
- **상태 표시줄** (창 아래, 보기 → 상태 표시줄로 켜고 끔): 연결 상태, 접속 대상, 인코딩, 로그 기록 중 표시,
  터미널 크기(열×행), 이 연결에서 받은/보낸 데이터(↓/↑, 암호화 해제 후 바이트), Caps Lock · Num Lock 상태.
- 글꼴 크기: **Ctrl+휠**, **Ctrl+= / Ctrl+- / Ctrl+0** (보기 메뉴에도 있음). 바꾼 크기는 저장됩니다.
- **찾기 (Ctrl+Shift+F)**: 화면과 스크롤백에서 글자를 찾습니다. Enter 로 위(이전 출력), Shift+Enter 로 아래.
  보이는 일치 항목은 노란색, 현재 항목은 선택 영역으로 표시되어 바로 복사할 수 있습니다. 소문자로만 쓰면 대소문자를 구분하지 않습니다.

## 자동 로그인

사이트 관리 창의 **자동 로그인** 에서 "프롬프트 → 입력" 단계를 정해 두면, 접속 후 그 프롬프트가 나올 때 자동으로 입력합니다.
Telnet 장비·시리얼 콘솔의 로그인이나, SSH 로그인 뒤의 명령(`sudo -i` 등)에 씁니다.

| 기다릴 문자열 | 보낼 내용 |
|---|---|
| `login:` (또는 `Username:`) | `{user}` |
| `Password:` | `{password}` |

- 화면의 줄이 **기다릴 문자열로 끝나면** 보낼 내용과 Enter 를 입력합니다 (대소문자 무시). "Last login: ..." 같은 줄에는 반응하지 않습니다.
- `{user}` 는 사이트의 사용자 이름, `{password}` 는 볼트에 저장된 비밀번호로 바뀝니다 (Telnet·시리얼 사이트도 사용자 이름과 비밀번호를 저장할 수 있습니다).
- 단계는 순서대로 한 번씩 실행되고, 다음 단계는 새 줄이 나온 뒤에 확인합니다. 직접 입력을 시작하면(Enter 만 누르는 것은 제외) 자동 로그인은 멈춥니다.
- 다음 프롬프트가 1분 안에 나오지 않으면 멈춥니다. 한참 뒤에 나온 `Password:`(다른 프로그램의 출력 등)에 비밀번호를 입력하지 않기 위해서입니다.
- 비밀번호가 저장되어 있지 않으면 그 단계에서 멈추고 알려 줍니다.

## 동시 입력

여러 장비에 같은 명령을 넣을 때 씁니다. **Ctrl+Shift+I** (또는 탭 메뉴 → 모든 탭에 동시 입력) 로 켜고 끕니다.

- 켜져 있으면 지금 탭에서 치는 키·붙여넣기가 **연결된 다른 탭에도 똑같이** 입력됩니다. 각 탭의 인코딩과 커서 키 모드에 맞춰 보냅니다.
- 탭 바에 주황색 `동시 입력 켜짐 · 다른 탭 N개` 와 [끄기] 가 표시되고, 함께 입력되는 탭은 제목이 주황색입니다.
- 특정 탭을 빼려면 탭 우클릭 → **동시 입력에 포함** 체크를 해제합니다. 연결되지 않은 탭(로컬 명령 프롬프트)은 받지 않습니다.

## 명령 입력창

터미널 아래에 명령을 미리 써 두고 보내는 입력창입니다. 보기 → **명령 입력창** 또는 **Ctrl+Shift+M** 으로 켜고 끕니다(다음 실행에도 유지).

- **Enter** 로 보내고, **Shift+Enter** 로 줄을 바꿉니다. 여러 줄은 한 줄씩 Enter 와 함께 입력됩니다. 비워 두고 Enter 를 누르면 Enter 만 보냅니다.
- **↑ / ↓** 로 이전에 보낸 내용을 다시 불러옵니다.
- 보낼 곳: **현재 탭**(동시 입력이 켜져 있으면 그 탭들도) 또는 **모든 탭**(연결된 탭 전부, '동시 입력에 포함' 을 끈 탭 제외).

## 접속 유지 · 절전 방지

오래 켜 둔 세션이 끊기지 않도록 사이트마다 **접속 유지** 를 정합니다 (사이트 관리 창 → 접속 유지). 정한 시간 동안 보낸 것이 없을 때만 보냅니다.

| 방식 | 보내는 것 | 막아 주는 끊김 |
|---|---|---|
| 프로토콜 신호 (기본, 60초) | SSH keepalive 요청, Telnet `IAC NOP` | 방화벽·공유기·서버의 무통신 끊김. 응답 없는 SSH 연결도 알아챔 |
| 문자열 입력 | 정한 문자열을 입력한 것처럼 (기본 `\x20\b` = 스페이스+백스페이스) | 장비·셸의 입력 대기 자동 로그아웃 (Cisco `exec-timeout`, `TMOUT`) |
| 끔 | 없음 | |

- 문자열에는 `\r`(Enter), `\n`, `\t`, `\b`(백스페이스), `\e`(Esc), `\\`, `\xHH` 를 쓸 수 있습니다. 스페이스+백스페이스는 치던 명령을 건드리지 않지만, `--More--` 같은 페이저에서는 스페이스가 다음 쪽으로 넘깁니다.
- 시리얼에는 프로토콜 신호가 없으므로 문자열 입력을 쓰세요.

**절전 방지** (설정 → 절전 방지): 연결된 세션이 있는 동안 Windows 가 유휴 상태로 절전에 들어가 연결이 끊기는 것을 막습니다.
기본값은 "연결 중에는 절전 모드 안 함" 이고, "화면도 켜 둠" 이나 "끔" 을 고를 수 있습니다. 동작 중에는 상태 표시줄에 `절전 방지` 가 보입니다.
덮개를 닫거나 직접 절전을 고르면 그대로 절전합니다.

**화면보호기 진입 방지** (도구 메뉴, 체크 상태는 다음 실행에도 유지): 켜 두면 연결 여부와 관계없이 화면보호기가 켜지지 않습니다.
절전 방지 신호로는 화면보호기를 막을 수 없어서, PC 가 30초 넘게 입력이 없으면 제자리 마우스 이동(움직이지 않는 0 거리 입력)을 보내 유휴 시간을 초기화합니다.
그래서 유휴 시간에 따른 화면 꺼짐·자동 잠금도 함께 미뤄집니다. 동작 중에는 상태 표시줄에 `화면보호기 방지` 가 보입니다.

## 인코딩 자동 감지

사이트의 인코딩을 **자동 감지**(새 사이트의 기본값)로 두면, 받은 출력이 UTF-8 인지 CP949 인지 스스로 판단합니다.
한글이 두어 글자 나오면 결정되고, CP949 로 결정되면 그전에 깨져 보이던 출력도 다시 그립니다(연결 전 프롬프트 줄은 글자만 유지).
상태 표시줄에 `CP949 (EUC-KR) (자동 감지)` 처럼 표시됩니다. 직접 UTF-8 / CP949 를 지정하면 감지하지 않습니다.

## 시리얼 · 로그

- 연결 창에서 프로토콜 **Serial** → COM 포트(목록/직접 입력), 속도, 데이터 비트, 패리티, 정지 비트, 흐름 제어.
- 탭 우클릭 → **BREAK 신호 보내기** (시리얼: 300ms line break, Telnet: `IAC BRK`) — 장비 ROMMON 진입·비밀번호 복구용.
- 세션 로그: 사이트 관리 창의 "세션 로그" 에서 자동 기록을 켜거나, 탭 우클릭 → 로그 메뉴에서 수동으로 시작/중지.
  - 텍스트: 제어 문자·색상 코드를 뺀 출력 (UTF-8, 줄마다 시각 표시 선택)
  - 원본: 받은 바이트 그대로
  - 기본 폴더: `문서\playterm-logs`, 파일 이름: `세션이름_YYYYMMDD_HHMMSS.log`

## SFTP · 포트 포워딩

- SSH 탭에서 **Ctrl+Shift+E** (또는 탭 바의 [SFTP] / 탭 우클릭 메뉴) → 파일 브라우저.
- **SFTP 탐색기 (옆 패널)**: 도구 → SFTP 탐색기 또는 **Ctrl+Shift+X**. 창 오른쪽에서 패널이 밀려 나와 터미널 옆에 붙고, 지금 탭의 원격 파일을 보여 줍니다(탭을 바꾸면 따라 바뀜).
  업로드 / 폴더 업로드 / 다운로드 / 새 폴더 / 삭제 버튼, 더블클릭으로 폴더 열기·파일 다운로드, 탐색기에서 끌어다 놓아 업로드. 패널 왼쪽 가장자리를 끌어 폭을 바꿀 수 있습니다.
- 다운로드는 옆에 임시 파일(`.이름.….part`)로 받은 뒤 다 받으면 바꿔 넣으므로, 실패하거나 취소해도 원래 있던 파일은 그대로입니다.
  서버가 준 이름이 이 PC 에 쓸 수 없거나 폴더 밖을 가리킬 수 있으면(`..`, `\`, `:`, `CON` 같은 장치 이름 등) 받지 않고 알려 줍니다.
- SFTP 창과 탐색기 패널은 **터미널(셸)의 현재 디렉터리**에서 열립니다. **[터미널 위치]** 버튼으로 언제든 그 위치로 다시 갑니다.
  같은 SSH 연결에 보이지 않는 채널을 하나 더 열어 셸 프로세스의 디렉터리(`/proc/<셸>/cwd`)를 읽으므로, 셸 설정이 필요 없고 터미널에는 아무것도
  입력되지 않습니다. 중첩된 셸(`bash` 안의 `bash`)도 따라갑니다. Linux 서버에서 동작하며, 알 수 없으면(다른 OS, `sudo` 로 바뀐 사용자의 셸 등)
  로그인 디렉터리에서 엽니다.
- 다운로드가 끝나면 전송 목록에 **[폴더 열기]** 가 생겨, 받은 파일이 선택된 상태로 Windows 탐색기가 열립니다(SFTP 창과 탐색기 패널 모두).
- 파일 목록은 아이콘으로 구분합니다: 폴더는 노란 폴더, 파일은 종류별 색 띠(이미지 초록 · 압축 보라 · 코드 파랑 · 스크립트 주황 · 설정 청록 · 문서 빨강 · 미디어 분홍 · 실행 파일 진한 빨강, 텍스트·기타는 줄무늬).
  심볼릭 링크는 작은 화살표가 붙고, 숨김 파일(. 으로 시작)은 흐리게 보입니다.
  폴더 이동, 업로드(파일/폴더, 창에 끌어다 놓기), 다운로드(폴더는 통째로), 새 폴더, 이름 바꾸기, 삭제, 전송 진행률/취소.
- **여러 개 선택**: Ctrl+클릭(하나씩 더하기/빼기), Shift+클릭(범위), Ctrl+A 또는 목록 머리의 체크박스(모두). [다운로드 (N)] · [삭제 (N)] 와
  우클릭 메뉴의 '선택한 N개 다운로드/삭제' 가 선택한 항목 전부에 적용됩니다. 여러 개를 받을 때는 받을 폴더를 한 번 고릅니다.
  목록을 클릭한 뒤에는 Delete 로 삭제(확인 후), Esc 로 선택 해제를 합니다.
- 포트 포워딩은 사이트 관리 창의 "포트 포워딩" 에서 설정하며, 접속하면 자동으로 시작됩니다.
  - 로컬 (L): 이 PC 의 포트 → 서버에서 대상으로 연결
  - 원격 (R): 서버의 포트 → 이 PC 에서 대상으로 연결
  - 동적 (D): 이 PC 에 SOCKS5 프록시

## ZMODEM 받기 (sz)

- 서버에서 `sz 파일...` 을 실행하면 터미널이 ZMODEM 전송을 알아채고 파일을 이 PC 로 받습니다. SSH · Telnet · 시리얼 모두 됩니다(서버에 lrzsz 필요).
- 저장 위치는 **도구 → 설정 → ZMODEM 받을 폴더** (기본은 Windows 의 다운로드 폴더). 같은 이름의 파일이 있으면 덮어쓰지 않고 `이름 (1).확장자` 로 저장합니다.
- 받는 동안 터미널에 파일별 진행률이 나오고, 끝나면 받은 파일과 저장 위치를 알려 줍니다. **Ctrl+C**(또는 Esc, Ctrl+X)로 취소합니다.
- 데이터 블록마다 CRC(16/32비트)를 확인해 깨진 부분은 그 위치부터 다시 받고, 끝까지 받은 파일만 남깁니다(받는 중의 파일은 임시 이름으로 쓰다가 마지막에 이름을 붙임).
  취소하거나 연결이 끊기면 받던 파일은 지웁니다. 서버가 보낸 파일 이름은 경로를 떼고 Windows 에서 쓸 수 없는 문자를 바꿔, 받을 폴더 밖에 저장되지 않습니다.
- 서버가 이 PC 에서 명령을 실행하라고 요청하는 ZCOMMAND 는 거부합니다. 서버의 `rz`(이 PC 에서 보내기)는 아직 지원하지 않아 자동으로 취소하므로, 파일을 보낼 때는 SFTP 를 쓰세요.

## 원격 데스크톱 (RDP)

Windows 원격 데스크톱 서버에 접속해 탭 안에 화면을 그립니다 (mstsc 를 띄우지 않고 playterm 이 직접 접속).
사이트 관리 창에서 프로토콜 **RDP** 를 고르거나, 프롬프트에서 `rdp [사용자@]호스트[:포트]`, 명령줄에서 `playterm rdp://사용자@호스트`.

- 연결: TCP → TLS → **NLA (CredSSP/NTLM)**. 사용자는 `사용자` 또는 `DOMAIN\사용자`. 비밀번호가 없거나 틀리면 묻고(3번까지), 비밀번호 창의 '비밀번호 저장' 으로 볼트에 저장할 수 있습니다.
- **서버 인증서**: RDP 서버는 대개 자체 서명 인증서라서, SSH 호스트 키처럼 처음 접속할 때 지문(SHA-256)을 보여 주고 신뢰하면 `known_rdp_hosts` 에 기억합니다. 나중에 인증서가 바뀌면 접속을 거부합니다.
- **화면 크기**: 기본은 '탭 크기에 맞춤' — 창이나 사이트 목록·SFTP 패널로 탭 크기가 바뀌면 원격 해상도도 따라 바뀝니다(디스플레이 제어 채널을 지원하는 서버). 1920×1080 같은 고정 크기도 고를 수 있고, 탭보다 크면 비율을 유지해 줄여 보입니다.
- **키보드**: 글자(한글 IME 포함)는 유니코드로 보내 원격 키보드 배열과 관계없이 그대로 입력되고, Enter·방향키·F1~F12·Ctrl/Alt 조합은 키(스캔 코드)로 보냅니다. playterm 단축키(Ctrl+Shift+…, Ctrl+Tab, Alt+←/→, F11)는 원격으로 가지 않습니다.
- **마우스**: 이동·왼쪽/오른쪽/가운데 버튼·휠. 원격 커서를 화면에 그려 보여 줍니다.
- **클립보드 공유** (사이트 설정, 기본 켬): Windows 클립보드와 원격 클립보드를 맞춰 복사·붙여넣기가 됩니다.
- 명령 입력창·동시 입력으로 보낸 글자도 RDP 탭에 입력됩니다.
- 아직 지원하지 않는 것: 소리, 드라이브·프린터 공유, RD 게이트웨이, Kerberos(도메인 환경에서도 NTLM 으로 인증).

테스트용 RDP 서버: `tools\dev-rdpd` (`cargo run --release` → 127.0.0.1:3389, tester / secret). 화면에 마우스를 따라가는 십자선을 그리고, 받은 키보드·마우스 입력을 출력합니다.

## SSH 인증 순서

1. 세션에 지정한 키 파일 (OpenSSH 형식 / PuTTY `.ppk`, 암호가 걸려 있으면 passphrase 입력)
2. SSH 에이전트 — `SSH_AUTH_SOCK` 이 named pipe 이면 그것, 아니면 Windows OpenSSH 에이전트(`\\.\pipe\openssh-ssh-agent`), 그다음 Pageant
3. 기본 키 파일 `~/.ssh/id_ed25519`, `id_ecdsa`, `id_rsa` (있을 때만)
4. 저장된 비밀번호
5. keyboard-interactive / 비밀번호 입력

RSA 키는 서버가 알려주는 `rsa-sha2-512` / `rsa-sha2-256` 으로 서명합니다.

비밀번호 칸(로그인, 키 암호, 볼트 마스터 비밀번호, 사이트의 비밀번호)에서는 입력기(IME)를 끕니다. 터미널에서 한글을 쓰던 상태여도
비밀번호는 영문으로 입력되므로, 가려진 칸에 `ㄴㄷㅊㄱㄷㅅ` 이 들어가 로그인이 실패하는 일이 없습니다. 창이 닫히면 한/영 상태는 그대로 돌아옵니다.

사용자 이름을 잘못 넣었으면 비밀번호 입력 창의 **사용자** 칸에서 고칠 수 있습니다. SSH 서버는 인증 도중 사용자 변경을 허용하지 않으므로 새로 연결해서 그 사용자로 로그인하며, 저장된 사이트라면 **사이트 정보에도 저장** 을 체크해 사이트의 사용자 이름도 바꿀 수 있습니다.

비밀번호 입력 창의 **비밀번호 저장** 을 체크하면(저장된 사이트에서), 로그인에 성공한 뒤에 그 비밀번호를 볼트에 저장하고 사이트를 '비밀번호 저장' 으로 바꿉니다. 틀린 비밀번호는 저장되지 않고, 볼트가 잠겨 있으면 잠금 해제(처음이면 만들기)를 묻습니다. 그 창을 취소하면 아무것도 바뀌지 않습니다.
비밀번호를 먼저 통과한 뒤 묻는 일회용 코드(OTP) 같은 추가 인증에는 저장된 비밀번호를 보내지 않고, 그 값을 비밀번호로 저장하지도 않습니다.

볼트를 **잠그면** 열린 탭에 넘겨준 비밀번호도 지웁니다. 그 탭을 다시 연결하면 볼트 잠금 해제를 먼저 묻습니다. '마스터 비밀번호를 잊었나요?' 로 볼트를 초기화하면 기존 파일은 `vault.toml.bak` 으로 남겨 둡니다.

## 설정 파일

`%APPDATA%\playterm\config\` (환경변수 `PLAYTERM_CONFIG_DIR` 로 변경 가능 — 포터블 사용)

| 파일 | 내용 |
|---|---|
| `sessions.toml` | 저장된 세션과 템플릿 (비밀번호 없음) |
| `settings.toml` | 언어, 화면 테마, 글꼴, 크기, 색 테마, 스크롤백, 상태 표시줄, 명령 입력창, 절전 방지, 화면보호기 진입 방지, 연결 시간 제한, 복사 / 붙여넣기 키, 사이트 관리 보기(트리/그리드), ZMODEM 받을 폴더 |
| `vault.toml` | 저장된 비밀번호. 마스터 비밀번호 → Argon2id → XChaCha20-Poly1305 로 암호화. 비밀번호마다 저장할 때의 접속 대상(프로토콜·사용자·호스트·포트)도 함께 암호화해 두어, `sessions.toml` 에서 사이트의 대상이 바뀌면 그 비밀번호를 보내지 않습니다(playterm 에서 직접 고친 경우는 따라감). 창을 여러 개 띄워도 서로 저장한 비밀번호를 지우지 않습니다 |
| `known_hosts` | SSH 호스트 키. 알려진 호스트의 키가 바뀌면 — 종류가 다른 키여도 — 접속을 거부합니다(중간자 공격 방지). 알고 있는 키 종류를 먼저 요청합니다 |
| `known_rdp_hosts` | RDP 서버 인증서 지문. 바뀌면 접속을 거부합니다 |

## 개발

```powershell
cargo test --workspace                              # 단위 + SSH 루프백 통합 테스트
cargo run -p playterm-net --example dev_sshd        # 127.0.0.1:2222 테스트 SSH 서버 (tester / secret)
cargo run -p playterm-net --example dev_sshd -- --authorized-keys key.pub --sftp-root C:\temp   # 공개키 인증 / SFTP 루트
cargo run -p playterm -- ssh://tester@127.0.0.1:2222
```
